# 🛒 E-Commerce SQL Analysis Project

## 📌 Project Overview

This project is an end-to-end SQL practice and analytics project built using an E-Commerce database.
It focuses on solving real-world business problems related to:

* Customer Analysis
* Inventory Monitoring
* Revenue Insights
* Sales Performance
* Order Trends
* Product Analytics
* Payment Method Analysis

The project contains multiple SQL queries ranging from beginner to intermediate concepts using filtering, joins, aggregations, grouping, sorting, and date functions.

---

# 🗂️ Database Used

**Database Name:** `ecommerce_interview`

---

# 🏗️ Tables Created

The project includes the following relational tables:

| Table Name  | Description                          |
| ----------- | ------------------------------------ |
| customers   | Stores customer information          |
| products    | Stores product and inventory details |
| orders      | Stores order-level information       |
| order_items | Stores item-wise order details       |

# 📊 Business Problems Solved

## Part 1 — Customer & Inventory Filtering

Business Requirement:
The marketing and inventory teams want to identify customer acquisition trends and inventory risks.

### Queries Included

* Find customers from specific cities
* Identify customers based on signup dates
* Filter products by category
* Find products above a certain price range
* Detect low stock products
* Identify products within stock ranges
* Search customers using pattern matching
* Find products using keyword search
* Extract customers registered in a specific year

---

## Part 2 — Revenue & Sales Analysis

Business Requirement:
The finance department wants summarized revenue and sales insights.

### Queries Included

* Total revenue generated by category
* Total quantity sold per product
* Order count by status
* Revenue by payment method
* Average product price category-wise
* Category-wise quantity sold
* Monthly order analysis
* Monthly revenue trend
* Most commonly used payment method
